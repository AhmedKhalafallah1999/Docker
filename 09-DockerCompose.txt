 1- you need to put/ identify the docker compose version,

version: "3"
 
 2- you need to identify the services of your app like,
 DB, node, php ... and so on

 services:
  node-app:
    container_name: express-node-app-container 

3- now like in the long terminal you just need to identify
the port due to the container env is islated so you need 
to forward to another port, and volume for binding 
here, you can use relative path normally,,,...
services:
  node-app:
    container_name: express-node-app-container 
    volums: 
      - ./src:/app/src:ro
    ports:
      - "4000:4000"
    env_file:
      - ./.env

 4- lastly you need to give him the build cmd to search 
 docker file to execute to install the package needed for this services,
 then create a volume, and make mapping for ports...

 version: "3"
services:
  node-app:
    container_name: express-node-app-container
    build: .
    volums: 
      - ./src:/app/src:ro
    ports:
      - "4000:4000"
    env_file:
      - ./.env
    build: .
